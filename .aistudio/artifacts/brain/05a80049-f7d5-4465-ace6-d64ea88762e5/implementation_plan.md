# Pembuatan Dokumentasi README.md untuk FotoSync

## Tujuan
Membuat file dokumentasi `README.md` yang komprehensif dalam Bahasa Indonesia untuk aplikasi **FotoSync**, mencakup ikhtisar proyek, fitur utama, arsitektur, dan panduan penggunaan.

## Rencana Implementasi

1. **Membuat File `README.md` di Root Direktori (`/README.md`)**
   - **Judul & Deskripsi**: Pengenalan FotoSync sebagai aplikasi Android manajemen sesi foto profesional dengan Local HTTP Server & Portal Klien QR Code.
   - **Fitur Utama**:
     - Manajemen Sesi Foto (Klien, Tanggal, Kategori, Catatan).
     - Local Ktor HTTP Server & Portal Klien (Akses via browser jaringan lokal/Wi-Fi dengan QR Code).
     - Penyimpanan SAF (Storage Access Framework) untuk jalur folder penyimpanan fleksibel.
     - Unduh & Ekspor Foto (ZIP).
     - Suka/Like foto dan galeri interaktif.
   - **Arsitektur & Teknologi**:
     - Kotlin & Jetpack Compose (Material Design 3).
     - MVVM Architecture & Room Database.
     - Ktor Server untuk Local Web Sharing.
   - **Panduan Penggunaan**: Cara membuat sesi, menjalankan server lokal, membagikan QR Code ke klien, dan mengelola penyimpanan.

2. **Verifikasi & Finalisasi**
   - Meninjau kelengkapan dan format Markdown.
   - Memastikan kesesuaian dengan fitur aplikasi saat ini.
